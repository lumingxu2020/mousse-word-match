# 慕斯的小工具 · 中英消消乐

适合孩子的中英文单词配对应用，包含 92 个课本词语、按单元与分类练习、九关闯关、各关最高分累计总分、语音朗读、主题切换和图片 OCR 导入。

`portal/` 提供独立的工具导航门户，支持学习、工作、生活分类和后台配置。

## 本地运行

需要 Node.js 20 或以上版本。

```sh
npm start
```

默认端口为 3093。通过 `PORT`、`DATA_DIR` 和 `WORD_MATCH_ADMIN_TOKEN` 设置端口、数据目录与词库管理密码。未配置密码时，首次启动会在数据目录生成 `admin-token.txt`。

图片识别需要安装 Tesseract 及 `eng`、`chi_sim` 语言包；识别结果应校对后导入。

```sh
npm test
```

## NAS 部署

参考 [部署说明](deploy/nas/README.md)，使用 Docker Compose 启动。复制环境变量示例并设置独立管理密码，勿提交真实 `.env` 或运行数据。

闯关成绩保存在当前浏览器；共享词库保存在服务端数据目录。总分为九个关卡各自最高分之和。
